# Cloud Infrastructure Fundamentals Lab Report

## Project Purpose
This repository serves as a complete laboratory report detailing fundamental cloud computing concepts, hands-on Linux system inspection, major cloud service provider analysis, and high-level architectural diagramming. The primary goal of this project is to demonstrate practical competency in navigating cloud server environments using command-line interface tools and explaining how cloud components work together in modern web application setups.

## Repository File Structure

* **`infrastructure-report.md`**: Contains detailed hardware specifications retrieved directly from an active Linux cloud virtual machine. It includes key metrics such as CPU architecture model, core count, available total system RAM, and main disk drive capacity.
* **`cloud-provider-comparison.md`**: Provides a comparative breakdown of key infrastructure offerings across Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). It includes answers to guiding research questions regarding platform strengths, enterprise tool integration, artificial intelligence features, and general cloud similarities.
* **`reflection.md`**: Outlines personal learning insights, technical challenges faced while reading Linux command outputs, solutions applied to resolve confusion, and key takeaways from the assignment.
* **`screenshots/cloud-architecture.png`**: Displays a clear cloud architecture diagram showing the visual flow of traffic from a user through the public internet into a secure Virtual Private Cloud (VPC) housing compute servers and storage drives.

## Conclusion
This lab successfully demonstrates fundamental skills in cloud resource monitoring, cloud ecosystem research, and basic cloud network topology design.
