# Reflection
In this lab activity, I learned how real servers work and how to check their parts using simple computer commands. I used a terminal to log into a remote server and typed commands like lscpu, free -h, and df -h to see key details. These commands showed me the server CPU type, how much RAM memory was available, and how much hard drive storage space was left. At first, reading the disk storage numbers was confusing because the screen showed a lot of extra system lines. I fixed this by learning to look specifically for the main root slash symbol line, which points to the real hard drive, and using the -h option so the numbers appeared in easy-to-read gigabytes instead of raw bytes. I also learned about the big cloud companies like Amazon Web Services, Microsoft Azure, and Google Cloud. I saw that all three offer similar basic tools, like virtual computers, file storage, and private networks, but each has special strengths for different tasks. Lastly, drawing the cloud diagram helped me understand how everything connects together in a real setup. I saw how a user sends data over the public internet into a protected Virtual Private Cloud, where a server processes the information and saves it inside a storage drive. Overall, this hands-on project was a great practice that built my confidence in using Linux terminals, understanding real server hardware, and designing clean cloud setups for future work.
