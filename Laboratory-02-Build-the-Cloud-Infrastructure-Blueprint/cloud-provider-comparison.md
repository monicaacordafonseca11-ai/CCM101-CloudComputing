| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
AWS has the most services because it was started first. It gives users the largest choice of tools for databases, servers, and app building.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is best because it works easily with Windows, Office, and other Microsoft software. It also helps companies save money if they already own Microsoft licenses.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud (GCP) is the leader in AI and Kubernetes. Google actually created Kubernetes, and they build powerful tools for smart AI features.

### 4. What similarities did you observe among the three cloud providers?
All three offer virtual servers, file storage, private networks, and safety settings. They also let you pay only for what you use.
